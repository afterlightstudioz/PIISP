PIISP
PiiSP is a from-scratch PlayStation Portable emulator built to run on Nintendo Wii hardware. Written entirely in-house with a custom MIPS-to-PowerPC JIT recompiler, PiiSP takes the PSP's 333 MHz MIPS32 architecture and translates it on the fly into native PowerPC instructions for the Wii's 729 MHz Broadway processor.

Built from the ground up. No forks, no borrowed cores — every component, from the instruction decoder to the memory manager, was written specifically for this project.
The goal: prove that the Wii - a 2006 console with 88 MB of RAM and a 729 MHz CPU can do what most people assumed was impossible.
